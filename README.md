Currently pursuing a **B.Tech in Electrical Engineering at IIT Bhubaneswar**, with a focus on **Artificial Intelligence, Machine Learning, RAG systems and backend engineering**.

Worked as an **AI Research Intern at IIT Bhubaneswar**, where I developed and evaluated a Multi-Agent RAG system using LangGraph, FAISS and AWS Bedrock. The system achieved **94.2% faithfulness, 70.0% correctness and 48.9% Token F1**, outperforming the traditional RAG baseline on 21 of 30 multi-hop questions.

I enjoy building practical AI systems, backend services and full-stack applications, with particular interest in **Agentic AI, RAG, Machine Learning and System Architecture**.

### Projects

**Forecast.ai — Demand Forecasting**

Machine-learning application for demand forecasting using ARIMA, REST APIs and database-backed data processing.

- Built a Flask-based ML application with REST APIs for sales upload, demand prediction and forecast retrieval.
- Implemented ARIMA to identify demand patterns and predict future requirements.
- Integrated PostgreSQL for sales data and designed the workflow for data processing, forecasting and visualization.
- **Live:** [Forecast.ai](https://forecast-vk.onrender.com/)

---

**RagKit-vs — Multi-Agent RAG Library**

Open-source Python library for integrating Traditional RAG and LangGraph-based Multi-Agent RAG into applications.

- Developed during my AI Research Internship at IIT Bhubaneswar.
- Supports planner, step-definer, extractor and QA agent workflows.
- Built using LangGraph, FAISS and LLM APIs.
- Published as the Python package `ragkit-vs`.
- **PyPI:** [ragkit-vs](https://pypi.org/project/ragkit-vs/)

---

**SummAI — AI Text Summarizer**

Microsoft Edge extension that transforms webpages and selected text into summaries, flowcharts and learning roadmaps.

- Built and published using Manifest V3 with an Edge side panel.
- Backend powered by Groq-hosted Llama 3.3 70B.
- Returns structured JSON rendered as flowchart nodes and roadmap cards.
- **Edge Add-ons:** [SummAI](https://microsoftedge.microsoft.com/addons/detail/summai-%E2%80%93-text-summarizer/iilhbdhbacoojhhfhfagokiilglafjhj)
- **Code:** [GitHub](https://github.com/Varshitcode14)

---

**CNN-Based Irregular Mesh Generation**

Deep-learning based image-to-mesh generation system designed to replace computationally expensive DSP pipelines.

- Implemented SLP, MLP and CNN architectures.
- Achieved **82.31% recall** using CNN.
- Achieved up to **17× speedup** over traditional methods.
- **Code:** [GitHub](https://github.com/Varshitcode14)

---

**Grocto — Campus Grocery Platform**

Smart campus grocery delivery platform with real-time tracking and role-based access.

- Built a full-stack platform for campus grocery ordering and delivery.
- **Live:** [Grocto](https://grocto-frontend.onrender.com)
